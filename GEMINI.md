# Antigravity Workspace Configuration: selenium-java-template-bdd

## Overview
Ultra-lean Cucumber BDD test automation framework designed for rapid live coding sessions and automation technical interviews.
Automates Web UI via **Cucumber + Selenium WebDriver 4** and REST APIs via **Cucumber + REST Assured**.

---

## Tech Stack & Versions
- **Language**: Java 21 (Code & comments STRICTLY in English)
- **Build Tool**: Maven (`pom.xml`)
- **BDD Framework**: Cucumber Java 7.18.0 + Cucumber TestNG 7.18.0
- **Test Framework**: TestNG 7.4.0
- **UI Automation**: Selenium Java 4.22.0 + WebDriverManager 5.8.0
- **API Automation**: REST Assured 5.4.0 + Jackson
- **Configuration**: `src/main/resources/config.properties` + System properties overrides
- **Language Policy**: All code, comments, Javadocs, Gherkin scenarios, and commit messages MUST be in English regardless of the user's conversation language.
